# 接幅核查（相邻图幅交库前核查 / 批量更正）

Flask + SQLite 的接幅核查页：录入**应交范围**和最多 **100 张图幅**的编号与覆盖范围
（同一坐标系下的整数米矩形），列出应交范围内所有**有面积的缺片区**与**重叠区**
（重叠区标明全部相关图幅号）；一次可更正最多 **4 张图幅**，按整批替换后的覆盖判定，
通过后在同一事务里更新目录和核查结果。

## 运行

```bash
docker compose up --build
# 打开 http://localhost:8000

# 另开终端跑一遍演示脚本（预检 → 退回 → 更正 → 写入 → 过期版本）
./scripts/demo.sh
```

- 端口可用 `ADJCHECK_PORT=8080 docker compose up --build` 改。
- 数据保存在命名卷 `adjdata`（容器内 `/data/adjcheck.sqlite3`），`docker compose down` 不会丢；
  需要清空时 `docker compose down -v`。
- 容器以非 root 用户运行，带 `HEALTHCHECK`（`/healthz`），gunicorn 单 worker + 4 线程
  （SQLite 写入用 `BEGIN IMMEDIATE` + 版本号乐观锁，单 worker 使并发写串行且不跨进程争锁）。

首次启动会自动建一个示例项目 `DEMO-ADJ-001`：

| 项 | 值 |
| --- | --- |
| 应交范围 | `0 0 2000 1000` |
| 图幅 | `S1 0 0 1000 1000`、`S2 1100 0 2000 1000`、`S3 900 0 1400 500` |
| 初始缺片 | `1000 500 1100 1000`，50 000 m²（1 处） |
| 初始重叠 | `900 0 1000 500` × S1+S3，50 000 m²；`1100 0 1400 500` × S2+S3，150 000 m² |

页面上有两个示例按钮：

- **更正示例**：`S3 1000 0 1100 500` + 新增 `S5 1000 500 1100 1000` → 预检通过，
  消除旧缺片 50 000 m²、旧重叠 200 000 m²，无新位置问题；提交后目录变为 4 张、问题清零。
- **会退回的示例**：`S3 1050 0 1150 500` → 退回，原因“出现新的缺片位置：25 000 m²”，
  目录与核查结果保持原状。

## 规则实现

**问题判定**：把每张图幅裁到应交范围内，再用坐标压缩 + 扫描线划分成“覆盖集合恒定”的
矩形块。覆盖集合为空 → 缺片；≥2 张 → 重叠，并记录全部图幅号。面积恒为正，边界相接
不算重叠。只做矩形代数，**不按坐标跨度或面积循环**，耗时只随图幅数与问题块数增长。

**整批替换判定**（`service.build_plan`，纯函数、无副作用）：

1. 重算窗口 = 本批图幅**新旧范围**的并集（精确分解为互不相交矩形），并裁到应交范围；
2. 只对窗口内重新分析覆盖；窗口外沿用库中原有核查行（原 id 原样保留）；
3. 逐类比较“旧问题位置”与“新结果位置”的**面积差**（`area_outside`，同样只做矩形代数）：
   - `新位置问题面积 > 0` → 退回（缺片/重叠分别报面积）；
   - `消除面积（缺片+重叠）== 0` → 退回；
   - 类别不互换即可：只要不在**新位置**出现同类问题就通过（例如把缺片补上、同时消掉重叠）；
4. 通过后才进入写库：同一 SQLite 事务内替换本批图幅、删除窗口内旧核查行、写入新行、
   `version+1`、记审计日志；比较 `version` 失败或任何 SQL 异常 → 整体回滚，返回原因，
   目录与核查结果保持原状。退回的尝试只写一条 `rejected` 审计日志，不改目录/结果。

**数字口径**：所有坐标、面积都是整数（米、平方米），面积比较是精确相等，不做浮点容差。

**事务与并发**：写库前按 `version` 做乐观锁，`BEGIN IMMEDIATE` 串行化写入；若提交瞬间核查
结果行与页面读到的集合不一致（别处改过），拒绝合并并回滚。同一批更正并发提交时只有一个
成功，其余收到 409 且数据不变。

## 已知边界

- 只有整数米坐标；小数或其它坐标系单位需先换算。
- 没有登录/权限，适合内网或单机演示；`ADJCHECK_SECRET` 请自行替换。
- 退回/过期也会写一条审计行（便于追溯），但不改目录与核查结果。
- 图幅矩形可以超出应交范围，判定时只取与应交范围的交集。

## 接口

| 方法/路径 | 说明 |
| --- | --- |
| `GET /` | 项目目录 |
| `POST /projects` | 新建项目（校验后立即全量核查） |
| `POST /projects/<name>/delete` | 删除项目（级联删图幅与核查行） |
| `GET /projects/<name>` | 项目详情：覆盖示意图、缺片区、重叠区（含图幅号）、更正表单、审计记录 |
| `POST /projects/<name>/correct` | 无 JS 时的表单回退：`action=check` 预检 / `action=apply` 提交 |
| `POST /api/projects/<name>/check` | JSON 预检，返回判定、消除/新增面积、重算窗口 |
| `POST /api/projects/<name>/apply` | JSON 提交；退回 200 + `applied:false`，过期版本 409，写库失败 500 + 原因 |
| `GET /api/projects/<name>/state` | 当前目录、核查结果与统计 |
| `GET /healthz` | 健康检查 |

请求体：`{"batch":[{"no":"S3","x0":1000,"y0":0,"x1":1100,"y1":500}, ...], "version": 0}`；
`no` 已存在=替换，不存在=新增（累计图幅数不得超过 100）。

## 测试

```bash
python -m pip install -r requirements-dev.txt
python -m pytest tests -q
```

- `tests/test_geometry.py`：随机矩形与逐单元暴力覆盖对比、增量分块与全量结果一致、
  坐标放大 10⁶ 后结果结构不变（验证与跨度无关）、`subtract/union/area_outside` 精确性。
- `tests/test_service.py`：示例批次的判定与落库、退回场景、4 张上限、过期版本、篡改的计划、
  写失败回滚、随机 80 组用例“增量结果 ≡ 全量重算”，且窗口外行的 id 保持不变；
  另有 40 组用逐单元集合运算独立复核“消除面积 / 新位置面积 / 是否通过”。
- `tests/test_db.py`：`CHECK` 约束、级联删除、并发改动核查结果时拒绝合并、
  窗口外行复用、退回日志。
- `tests/test_web.py`：页面渲染（缺片区/重叠区/图幅号）、API 预检/提交/过期/写失败、
  表单回退、持久化重启。
